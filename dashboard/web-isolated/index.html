Движение камеры

Настройте обычный обзор и прицеливание отдельно. Профиль ARC Raiders: Hip/ADS gain 0.015, сглаживание 0, радиальная компенсация deadzone 0.12.

Общие параметры

Диапазон 0–0.99. Поднимает ненулевой сигнал стика. В профиле ARC Raiders: 0.12; в резервном профиле: 0.

Без измеренной LUT значение не участвует в расчёте. cm/360 также не участвует.

Y-scale и инверсия не поддерживаются этой сборкой.

Метаданные калибровки

Запишите реальные условия измерения. Эти записи не изменяют игру и не создают LUT.

Сохранить свою конфигурацию

При подключённом native-клиенте правки применяются и сохраняются автоматически. Без подключения доступно сохранение без применения.

Восстановление

Сначала выключаем захват и подтверждаем освобождение. Восстановленный профиль применяется автоматически при доступном native-клиенте; ввод остаётся выключенным.

Состояния профиля

Черновик существует в этом окне. «Применено» появляется после подтверждения клиента. «Сохранить без применения» только записывает профиль на Mac mini. После неопределённого результата используйте явное восстановление; повторной автоматической отправки не будет.

При конфликте сохраните профиль и checklist вместе отдельной копией. Обычный экспорт JSON по-прежнему содержит только профиль.

Контекстные действия PS5

E и R нажимают одну Square: взаимодействие или перезарядка по контексту игры. Клавиши 1 и 2 нажимают Triangle: смена/взять оружие, удержание убирает оружие. Они не выбирают прямые слоты.

Tab нажимает Touchpad: inventory, удержание открывает map. Кнопка «Круг» отвечает за приседание, двойное нажатие — за перекат. Текущая клавиша указана на схеме. L1 открывает предметы; IJKL задают направление правого стика для selector. Выбор лечения зависит от меню игры. Прямое лечение не подтверждено. R3 активирует навык.

Пользователь проверил: D-pad Up переключает фонарик, короткое нажатие D-pad Left открывает реплики, D-pad Right меняет плечо камеры. Действие «Удержать →» по одному нажатию удерживает D-pad Right 600 мс и отпускает его. Игровой результат этого удержания отдельно не подтверждён.

Действие «Перекат» автоматически выдаёт два нажатия приседа по 64 мс с отпусканием на 64 мс между ними. Если ручной присед уже зажат, сначала идёт отпускание на 64 мс. После второго нажатия идёт финальное отпускание на 64 мс, затем восстанавливается актуальное состояние ручного приседа. Удержание клавиши не повторяет последовательность, новые нажатия во время неё не ставятся в очередь. Cmd можно назначить на ручной присед, Caps Lock — только на «Перекат». При захваченном вводе назначенный Cmd + Space позволяет нажать присед и прыжок вместе.

Автотап огня включается отдельно. Интерфейс не определяет игровой контекст, автоматического лечения нет. Формирование команд проверено программно; распознавание удержания и переката в игре требует физической проверки пользователя.

Источники и ограничения

Проект создавался для ARC Raiders и вдохновлён XIM. Другие игры требуют своих назначений и настройки камеры. Автор получил бан в ARC Raiders во время использования проекта. Точная причина неизвестна; безопасность аккаунта не гарантируется.

Embark · 2.0 Frozen Trail · Embark · 1.45 quick cycle / wheel

Камера F(u) не измерена. Измеренной LUT нет, точное воспроизведение XIM не заявляется. Проверенный baseline сохраняет прежние gain и обработку движения.
