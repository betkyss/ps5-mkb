# Установка и первое подключение

## 1. Подготовьте устройства

Подключите Mac и PS5 Ethernet-кабелями к одному роутеру. На PS5 выберите проводное соединение и включите Remote Play в настройках системы. Клавиатуру и мышь подключите к Mac. Для мыши нужен доступный HID location ID; USB-мышь или USB-приёмник подходят для этой схемы. Bluetooth и трекпад отдельно не проверены.

Сборка рассчитана на Apple Silicon. Набор библиотек Homebrew должен поддерживать вашу версию macOS; старые версии системы и Intel Mac не проверены.

## 2. Соберите клиент

Установите инструменты командной строки Xcode (`xcode-select --install`), Homebrew и Git. Затем в Терминале:

```sh
git clone https://github.com/betkyss/ps5-mkb.git
cd ps5-mkb
brew install python cmake ninja pkgconf qt libplacebo ffmpeg sdl2 opus openssl@3 protobuf@29 miniupnpc speexdsp
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install protobuf
sh scripts/prepare-client.sh
sh scripts/build-client.sh
```

Первый скрипт скачивает закреплённую версию chiaki-ng и применяет патч. Второй собирает клиент в `build/client/gui/chiaki.app`. Сборка может занять несколько минут. Это локальная сборка с ad-hoc подписью, а не подписанный установщик.

## 3. Зарегистрируйте PS5

```sh
sh scripts/open-client.sh
```

В открывшемся chiaki-ng зарегистрируйте свою консоль через его форму регистрации. Включите Remote Play на PS5 и получите код в разделе привязки устройства. Укажите данные своего PSN-аккаунта, которые запрашивает клиент, и текущий код. Следуйте подсказкам клиента; код и регистрационные ключи не публикуйте.

Запишите точное имя зарегистрированной консоли. После регистрации полностью закройте клиент: дальнейшее подключение будет запускать пульт.

Если PS5 уже зарегистрирована в официальном chiaki-ng, вместо повторной регистрации можно закрыть оба клиента и выполнить:

```sh
sh scripts/import-settings.sh --copy-official-settings
```

Импорт копирует локальные настройки, не подключается к консоли и отказывается перезаписывать отличающиеся существующие значения. При конфликте используйте регистрацию в новом клиенте.

## 4. Выберите консоль и мышь

Посмотрите проводной IPv4-адрес PS5 в её настройках сети. Запустите:

```sh
python3 scripts/configure.py
```

Введите точное имя зарегистрированной PS5, её IP-адрес и выберите мышь из списка. Посмотреть обнаруженные мыши отдельно:

```sh
python3 scripts/configure.py --list-mice
```

Настройки сохраняются локально в `~/Library/Application Support/PS5MKB/connection.json`. После смены USB-порта location ID мыши может измениться: повторите настройку. При изменении адреса PS5 также повторите её; закрепление адреса в роутере избавит от таких изменений.

## 5. Запустите пульт

```sh
sh scripts/run-dashboard.sh
```

Откройте **http://127.0.0.1:8765**. Нажмите «Подключиться к PS5», дождитесь состояния подключения, затем «Включить клавиатуру и мышь».

При запросе macOS предоставьте клиенту разрешения на мониторинг ввода и управление компьютером в разделе конфиденциальности и безопасности. После изменения разрешений может потребоваться полностью закрыть клиент и запустить его снова из пульта.

**Esc освобождает ввод. Cmd + Esc переключает захват.** Не запускайте одновременно второй экземпляр chiaki-ng.

## Остановка

Сначала нажмите Esc или «Перейти на геймпад», затем закройте клиент. Сервер пульта остановите Ctrl + C в его Терминале или командой:

```sh
python3 scripts/stop-dashboard.py
```

Остановка сервера сама по себе не закрывает игровой клиент.

## Открыть пульт с другого устройства

По умолчанию сервер доступен только на этом Mac. Для доступа через Tailscale установите его на оба устройства и запустите сервер с собственным Tailscale IPv4-адресом Mac:

```sh
sh scripts/run-dashboard.sh --listen 100.64.0.2
```

`100.64.0.2` — пример: замените его адресом своего Mac. На втором устройстве откройте `http://ВАШ-TAILSCALE-IP:8765`. Для DNS-имени добавьте `--hostname` с собственным именем Mac в Tailscale. Доступ определяется вашей сетью Tailscale; отдельной формы входа у пульта нет. Сервер не предназначен для открытого интернета.

Клавиши в браузере другого устройства используются только при записи назначения. Игровой ввод по-прежнему поступает с Mac, где работает клиент.

## Где хранятся ваши данные

Профили, состояние и конфигурация пульта находятся в `~/Library/Application Support/PS5MKB/`. Регистрация консоли хранится отдельно в настройках клиента macOS. Ни то ни другое не требуется добавлять в Git.

Можно задать отдельный каталог параметром `--state-dir`; используйте один и тот же путь для `configure.py`, `run-dashboard.sh` и `stop-dashboard.py`. Не редактируйте `store.json` вручную, пока сервер работает. Файлы в `profiles/` — шаблоны; их изменение не обновляет текущий профиль запущенного пульта.
