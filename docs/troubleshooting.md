# Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| Страница не открывается | Запущен ли `sh scripts/run-dashboard.sh`? На том же Mac используйте http://127.0.0.1:8765. Для другого устройства нужен отдельно настроенный доступ через Tailscale. |
| Не найден клиент | Выполните подготовку и сборку из [инструкции](setup.md). Ожидаемый путь: `build/client/gui/chiaki.app`. |
| Пульт просит настроить PS5 и мышь | Выполните `python3 scripts/configure.py` с тем же `--state-dir`, который использует сервер. |
| Не удаётся подключиться к PS5 | Проверьте Remote Play, регистрацию консоли, точное имя и проводной IP-адрес. Закройте другие экземпляры chiaki-ng. |
| Мышь не найдена | Подключите USB-мышь или её приёмник и выполните `python3 scripts/configure.py --list-mice`. После смены USB-порта повторите настройку. |
| Есть соединение, но нет управления | Проверьте разрешения macOS, статус захвата и кнопку включения ввода. После выдачи разрешений перезапустите клиент. |
| Нужно немедленно вернуть управление Mac | Нажмите Esc. |
| Сохранено, но игра не изменилась | Сохранение и применение различаются. Проверьте подключение и подтверждение клиента в состоянии профиля. |
| Задержки или рывки | Оба устройства должны быть подключены Ethernet-кабелями к одному роутеру. Проверьте нагрузку сети и Mac. Параметры камеры подбираются отдельно для каждой игры. |
| Не работают прямые слоты оружия | Начальные назначения повторяют кнопки геймпада. Контекст и удержания обрабатывает игра. |
| После обновления не собирается клиент | Не обновляйте `vendor/chiaki-ng` отдельно: патч привязан к конкретному commit. Проверка `python3 scripts/verify-patch.py` покажет несовпадение. |

Если загрузка исходников оборвалась, сохраните свои изменения в `vendor/`, если они есть, и переместите незавершённый каталог за пределы проекта. Повторите `sh scripts/prepare-client.sh`.

При обращении с ошибкой укажите версию macOS, шаги воспроизведения и сообщение об ошибке. Перед публикацией логов удалите адреса устройств, имя консоли и данные регистрации. Не прикладывайте весь каталог состояния или настройки PSN.
